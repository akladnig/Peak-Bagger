## Implementation and policy audit

- All five hand-built forms receive the selected model-backed entity descriptor. `objectBoxAdminPermitsInput` consumes the descriptor's `canEdit` and structured input kind, the same metadata that composes Schema's `Read-only` attribute. Missing metadata/members, PKs (including assignable IDs) and explicitly generated values never produce direct inputs. No Attributes parsing, automatic form generation or independent production field allowlist was added.
- Every text input remains explicitly composed in its existing form through `objectBoxAdminTextFormField`; Peak Verified, Route Visible and Natural Feature's OSM / Manual selector use the same eligibility boundary. Preserve the exact supported field sets/control types, validators, coordinate alternatives/Calculate, duration parsing and Mark as HWC. Existing single-line inputs remain single-line.
- Converted all disabled read-only form text fields: Peak ID/grid zone, Natural Feature ID/OSM type/OSM ID/grid zone, Route ID, and PeakList ID/name/region. Peak source-of-truth now also uses selectable content beside its existing domain action. Contact displays its ID, with exact `Not yet assigned` only when its existing create flow has an actually unassigned generated PK. Assignable Peak IDs and valid stored zero/empty values are not relabelled. No placeholder is sent to a service.
- `ObjectBoxAdminReadOnlyFormValue` owns the visible label and reuses Work Item 03's complete, semantic-labelled, independently scrollable/selectable five-line value viewport. No read-only `TextField`/`TextFormField` or display-owned text controller remains; Peak's grid-zone display controller was replaced by a draft scalar. Existing Route geometry/PeakList membership displays continue through the shared detail helper.
- Peak notes and Route description use Flutter's active-style/TextScaler-aware `RenderEditable` measurement and internal full-draft scrolling, from a natural one-line minimum to a five-line content maximum. Labels and errors remain outside that content viewport. There is no fixed unscaled height, substring/ellipsis, separate draft or measurement-triggered save/cancel. Fields inherit the amended central decoration, without new local border overrides, field-associated tooltips, Search prefixes or submit buttons.
- The five stateful panes are keyed by entity/record/create identity. Same-record resizing/theme changes retain controllers and selections; record replacement disposes the prior draft and its input state. Shared read-only values retain record/field keys and own/dispose their selection/scroll resources. Existing mode/route cleanup remains intact.
- Service/data boundaries are unchanged. Unit regressions verify Peak identity and coordinate/duration/source-of-truth derivations; Natural Feature identity and operation-owned source-key maintenance; Contact ID/grouped validation; PeakList ID/name/region/all four hidden bounds; Route ID/geometry/elevations/waypoints/display cache/walking speed and its existing operation-owned timing regeneration. These legitimate derivations are not denied by direct-input policy. Source records remain unmodified until the existing persistence boundary.

## Deterministic verification

- `objectbox_admin_form_policy_test.dart` covers all five editors: independently enumerated expected text controls, intended boolean/selector controls, visible labelled/selectable IDs, no read-only TextField/TextFormField or mutation semantics, metadata-unavailable fail-closed presentation, generated/assignable/zero placeholder cases, and PK/generated flags overriding permissive metadata.
- Controlled pending/failing Save callbacks verify all five retain the same draft/controller for retry and leave editing only after successful completion. Record replacement disposes the former draft owner; removal disposes remaining resources. These tests perform no writes from rendering/selection and open no Store.
- Peak notes/Route description tests measure the actual editable content viewport for empty/short/long wrapped/newline drafts, scroll independently to an initially offscreen sentinel, copy that selection, retain complete text/selection/controller across resizing/theme/scale, and submit the full text. A long PeakList read-only form name is independently scrolled and mouse-selected/copied beyond line five using Cmd+C without mutation.
- Supported widget matrix: default/custom teal expressive light/dark themes, 1×/2× text, **1280 × 960 → 1600 × 960 → 1920 × 1200 → 1280 × 960**, with changed pane widths and reachable Save. Work Item 03's read-only metric/copy/semantics/detail/layout checks and existing browser/real-shell regressions are reused.
- Legacy editor test fixtures now supply real discovered policy rather than relying on missing metadata to enable inputs. Explicitly injected missing-metadata descriptors remain untouched for meaningful fallback coverage. Existing stable selectors are preserved across presentation-widget changes.
